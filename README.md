# Web Lab v2 — Học phát triển website bằng thực hành

## Mở trang

**Dễ nhất:** tải tệp `Web-Lab-Hoc-HTML-CSS-JavaScript.html` và mở bằng Chrome, Edge hoặc Firefox. Không cần cài gì, không cần Internet, không cần tài khoản.

**Làm việc với mã nguồn:** giải nén `Web-Lab-Ma-Nguon.zip`. Mở thư mục trong VS Code và mở `index.html` bằng trình duyệt hoặc Live Server. Các tệp phải cùng thư mục:

- `index.html` — giao diện trang học
- `style.css` — stylesheet của Web Lab
- `html-data.js` — 116 bài học HTML gốc (thẻ và thuộc tính)
- `extra-data.js` — bài học CSS, JavaScript, các khái niệm web và dự án mini
- `script.js` — điều hướng, tìm kiếm, editor, preview, console

## Sử dụng
1. Tìm bài học bằng thanh tìm kiếm (Ctrl+K) hoặc chọn nhóm HTML / CSS / JavaScript / Web.
2. Đọc giải thích, cú pháp, ví dụ; chọn tab HTML, CSS hoặc JavaScript để sửa code.
3. Nhấn `▶ Chạy thử` hoặc `Ctrl + Enter`. Đổi giữa Desktop và khung 375px để học responsive.
4. Mở Console dưới khung preview để xem `console.log()` và lỗi JavaScript.
5. Dùng `Sân chơi code` để tự tạo ví dụ và `Lộ trình` để học từng bước.
6. Đánh dấu hoàn thành / yêu thích; bản nháp và tiến độ lưu trong trình duyệt bằng localStorage khi có thể.

## Giới hạn kỹ thuật
- Preview chạy trong iframe sandbox tách biệt để tránh JavaScript ví dụ ảnh hưởng ứng dụng chính; một số API như localStorage/clipboard có thể bị hạn chế trong khung preview. Trang chính vẫn có thể lưu bài đã học khi trình duyệt cho phép.
- API ngoài chỉ hoạt động khi có mạng, máy chủ cho phép CORS, và trình duyệt cho phép truy cập.
- Git, npm, Node.js, database, React/Vue, SCSS... có bài giới thiệu/mô phỏng; muốn chạy công cụ thật bạn cần môi trường riêng trên máy.
- Không thực thi code trên máy chủ và không lưu code lên mạng.
