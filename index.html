WEB LAB TRÊN ĐIỆN THOẠI

Cài Web Lab như một app

Bạn có thể ghim website lên màn hình chính để mở nhanh, không cần App Store.

1Mở địa chỉ website HTTPS bằng Safari trên iPhone.
2Nhấn Chia sẻ (Share) rồi chọn Thêm vào Màn hình chính (Add to Home Screen).
3Bật Mở dưới dạng ứng dụng (Open as Web App), nếu có, rồi nhấn Thêm.

Để lưu bài học offline, cần tải đủ các tệp PWA lên GitHub Pages. Mở file HTML trực tiếp sẽ không đăng ký Service Worker. Tiến độ học lưu cục bộ trên thiết bị.

☁ Tài khoản và tiến độ

Đăng nhập để học tiếp trên điện thoại hoặc máy tính khác. Bài đã học, bài tập, bài yêu thích và nháp code sẽ được đồng bộ khi cấu hình đám mây hoàn tất.

🔧 Chưa bật đăng nhập. Chủ website cần kết nối Supabase trong file cloud-config.js và chạy SQL supabase-setup.sql, theo CLOUD-SETUP.md. Hiện tại Web Lab vẫn lưu tiến độ offline như trước.

Tài khoản mới có thể cần xác nhận email trước khi đăng nhập.
